# Python-pixi-cruft template

A [Cruft](https://cruft.github.io/cruft/) / [Cookiecutter](https://cookiecutter.readthedocs.io/) template for Python projects managed with [Pixi](https://pixi.sh).

## Usage

```bash
cruft create <repo-url>
```

Or with Cookiecutter directly:

```bash
cookiecutter <repo-url>
```
